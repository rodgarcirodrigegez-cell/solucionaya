# SolucionaYa — Fase 1

Primera versión funcional de la plataforma de herramientas online.

## Estructura

- `index.html` — estructura de la web.
- `styles.css` — diseño responsive y componentes visuales.
- `app.js` — catálogo, buscador y lógica de las 15 herramientas.
- `favicon.svg` — icono provisional.

## Cómo abrirla

La opción más sencilla: abre `index.html` con Chrome, Edge o Firefox.

### Nota sobre el QR

El generador QR utiliza `QRCode.js` desde CDN. Por ello, esa herramienta necesita conexión a Internet al abrir la página. El resto de la aplicación funciona sin backend.
